# Task Context

Build a Kotlin CLI that keeps structured Tagalog knowledge in SQLite and exports it to Anki. The domain model must remain independent of Anki.

Stack: Kotlin, Picocli, SQLite, Flyway, Exposed, JUnit 5. OrbStack/Docker is the authoritative build and test environment.

Before each task, read only this file and the relevant file in [`milestones/`](milestones/). Consult [`project-guide.md`](project-guide.md), [`conventions.md`](conventions.md), or [`roadmap.md`](roadmap.md) only when the task needs them. Update milestone checkboxes as work is completed; do not implement deferred features.
